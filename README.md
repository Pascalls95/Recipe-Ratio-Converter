# Recipe-Ratio-Converter
This is a website that I created to help easily convert ratios in recipes based on how many servings the recipe makes and how many you want. I did this project to continue testing my HTML and CSS skills, while also learning more JavaScript in a useful and interesting way. I also recently made a recipe planner website, and thought it would be a good idea to make a calculator to go with it. The website consists of one single page. The user first enters the amount of serves that the recipe makes and then the desired serves that they want. They can then either paste their recipe directly into the calculator, or add each ingredient and its amount manually. The converted amounts of each ingredient are there outputed below.

Please note, when pasting the recipe, the conversion will only properly work if it is in the correct order: Amount, Unit, Ingredient Name.

To run this project, simply open the deployed link that has been provided, enter values into each respective field.

AI was partially used in this project, only to learn how do do certain things within the JavaScript, such as using a formula to convert the ratios based on the serves and desired serves.
